Modelación · Semanas 3 y 4

Generador y pruebas de números pseudoaleatorios

Genera una secuencia rₕ en (0, 1), detecta su ciclo y valida que sea uniforme, con media 1/2, varianza 1/12 e independiente.

Los dos algoritmos

Uno es congruencial y el otro no; la diferencia está en si usan o no la operación módulo.

NO congruencial · no usa mod m

Cuadrados medios

Von Neumann & Metropolis, década de 1940.

Yi = (Xi)^2 Xi+1 = D dígitos centrales de Yi ri+1 = Xi+1 / 10^D
  1. Se parte de una semilla X₀ de D dígitos (D > 3).
  2. Se eleva al cuadrado: Yi = (Xi)².
  3. Se toman los D dígitos centrales de Yi → nuevo Xi+1 (si faltan dígitos se rellenan con ceros a la izquierda).
  4. Se normaliza dividiendo entre 10D para obtener ri en [0, 1).
  5. La salida se reutiliza como semilla. No garantiza periodo largo: puede degenerar a 0 (p. ej. semilla 1000).
CONGRUENCIAL · su núcleo es mod m

Congruencial lineal

D. H. Lehmer, 1951.

Xi+1 = (a·Xi + c) mod m ri = Xi / (m - 1)
  1. Parámetros enteros positivos: X₀ (semilla), a (multiplicador), c (constante aditiva) y m (módulo).
  2. Cada término es el residuo de dividir (a·Xi + c) entre m, por eso genera valores en {0, 1, …, m−1}.
  3. Se normaliza con ri = Xi / (m − 1) para llevarlo a (0, 1).
  4. Si c = 0 se llama multiplicativo; si c ≠ 0, lineal.
  5. Alcanza el periodo máximo N = m si se cumplen las condiciones de Banks, Carson, Nelson & Nicol.
